# Growth Without The Circus

PROJECT: DEVAVI MEDIA — PREMIUM PERFORMANCE MARKETING WEBSITE

Act as a world-class creative director, award-winning UI/UX designer, senior frontend engineer, and conversion-rate optimisation specialist.

Your task is to design and develop a complete, production-quality website for DEVAVI MEDIA, a performance marketing and growth agency.

This is not a generic agency website. It should look like a premium creative studio built by an experienced design agency.

1. DESIGN REFERENCE — VERY IMPORTANT

Use this website as the primary visual and structural design reference:

https://www.editcomedia.com/

Study its layout, typography, section composition, spacing, navigation, animations, interactions, colour usage, cards, and overall visual language.

I want a very similar design direction and level of visual quality.

Use the following characteristics:

Bold, oversized editorial typography.

Large hero section with strong visual hierarchy.

Minimal but impactful colour palette.

High-contrast typography.

Spacious layouts and generous whitespace.

Strong black-and-white sections.

Orange/red accent elements.

Asymmetrical grid compositions.

Large brand and portfolio visuals.

Scrolling marquee animations.

Smooth transitions and hover interactions.

Bold section headings.

Premium card designs.

Creative layouts rather than conventional corporate templates.

You may closely reproduce the reference's overall layout and interaction patterns, but replace all branding, content, imagery, and assets with original Devavi Media material.

Do not use Editco's logo, images, text, or branding.

The final result should feel like Editco's design quality and visual language, but with Devavi Media's own identity.
